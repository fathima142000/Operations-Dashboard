# Operations-Dashboard

### Overview
This project simulates an operational intelligence model built in Microsoft Excel to evaluate field service performance, maintenance backlogs, and resource allocation efficiency across regional districts.

### Key Features & Analysis
- **Dataset:** 50 structured field work records covering District, Asset Type, Priority Level, Days to Resolution, Cost Impact, and Status.
- **Pivot Table Modeling:** Nested grouping by District and Asset Type to calculate average resolution times and spot operational choke points.
- **Visualizations:** Clean executive bar charts tracking performance variance between rural regions (e.g., North Interlake) and urban centers (Winnipeg Central).

### Business Insights
- Rural service areas experience resolution delays significantly higher than urban centers, primarily driven by component availability bottlenecks in Substation and Distribution Line asset classes.
